# Brag Plan: Semi Filters

## What is this app?
Semi Filters is an online store for OEM-quality oil, air, fuel, and cabin filters built for semi trucks — pick your rig, find the filter, check out.

## The angle
Filters aren't glamorous. This video treats fleet filtration like a premium product film: dark shop energy, orange accent, and the real path from truck → fitment → cart. Specific to owner-operators and fleet managers, not generic ecommerce.

## Hook (first 2-3 seconds)
Giant brand mark (concentric orange filter circles) on `#0a0a0f`, then the line: **Premium Filters for Semi Trucks.**

## Key moments (the middle)
- Shop by truck: Volvo / Kenworth / Freightliner cards appear one by one
- Product moment: Oil / Air / Fuel / Cabin type chips + "Add to Cart"
- Checkout payoff: cart drawer with FIRST15, then **Order Confirmed!**

## Outro / punchline
Wordmark **SEMI FILTERS** + tagline: Keep your fleet running. semifilters.com

## User flow worth showing
1. Entry — hero → Shop All Filters / claim FIRST15
2. Key action — pick truck brand → product with fitment → Add to Cart
3. Result — Order Confirmed!

## Tone
- Preset: polished
- Creative direction: quiet premium fleet-parts product film
- Interpretation: Fewer scenes, longer holds, restrained SFX, confidence over hype. No startup parody energy.

## Format: landscape — 1920x1080
## Duration: 20 seconds

## Visual identity (from the project)
- Background: `#000000` (Apple-inspired dark primary)
- Card / secondary: `#1c1c1e`
- Accent: `#FF6B00`
- Text: `#f5f5f7`
- Secondary text: `rgba(235, 235, 245, 0.6)`
- Success: `#30d158`
- Display font: SF Pro / system UI stack (`-apple-system`, Helvetica Neue)
- Body font: same system stack
- Strongest visual element: Orange concentric-circle filter logo on pure black; Shop by Truck cards; FIRST15 promo

## Share copy (draft)
OEM-quality filters for semis — pick your truck, nail the fitment, stock the fleet. Semi Filters is live.
